# Leichter lesen

Web-App für Schülerinnen und Schüler mit Leseschwäche: Texte (eingefügt, aus Fotos, PDF oder Word)
werden in der Schrift OpenDyslexic und mit einstellbaren Lesehilfen angezeigt
(Größe, Abstände, Hintergrundfarbe, Silbenfärbung, Lesezeile).

- Läuft im Browser, auch offline (nach dem ersten Öffnen), auf iPad als Home-Bildschirm-App
- Fotos und Dateien werden nur auf dem Gerät verarbeitet, nichts wird hochgeladen
- Keine Anmeldung, keine Werbung, keine Datenerfassung
